# Definición del producto

Listly es una aplicación para gestionar una lista de compras compartida entre varios usuarios.

El objetivo principal es reflejar de forma simple y realista el proceso colaborativo de hacer compras del supermercado, permitiendo:

- Añadir productos a una lista común.

- Marcar productos como comprados.

- Registrar quién marcó (compró) qué, cuánto costó, y cuándo.

- Consultar un historial de compras grupal.

## Historias de usuario

1. Como usuario, quiero crear una nueva lista de compras para poder organizar mis productos antes de ir al supermercado.

2. Como usuario, quiero compartir una lista de compras con otras personas para que puedan colaborar modificando la lista.

3. Como colaborador de una lista, quiero añadir productos a una lista de compras para tener un registro claro de lo que necesito comprar.

4. Como colaborador de una lista, quiero editar o eliminar productos en una lista para mantener la lista actualizada y sin errores.

5. Como colaborador de una lista quiero marcar productos como comprados para saber qué artículos ya están en el carrito y cuáles faltan.

6. Como colaborador de una lista, quiero añadir el precio de compra a los productos adquiridos para poder llevar un historial de precios (7).

7. Como colaborador de una lista, quiero visualizar el historial de productos adquiridos para poder consultar el precio en compras anteriores.

8. Como colaborador de una lista, quiero poder ordenar o agrupar productos por categorías (frutas, lácteos, etc.) para facilitar la organización durante la compra.

9. Como usuario, quiero tener una interfaz simple y clara que me permita usar la app rápidamente sin complicaciones.

### Historias de usuario futuras

- Como usuario, quiero recibir notificaciones cuando alguien más actualice la lista compartida para estar siempre al tanto de los cambios.

- Como usuario, quiero acceder a la aplicación desde diferentes dispositivos para usar la lista donde me convenga.
